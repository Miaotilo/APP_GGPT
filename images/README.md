# 图片资源目录

本目录存放小程序所需图片资源。

## Tab 导航图标（必填）

请在 `images/tab/` 目录下添加以下图标文件（建议尺寸 48×48px，PNG格式）：

| 文件名 | 说明 |
|--------|------|
| `home.png` | 首页 - 未选中 |
| `home_active.png` | 首页 - 选中（金色） |
| `mode.png` | 共管模式 - 未选中 |
| `mode_active.png` | 共管模式 - 选中 |
| `process.png` | 合作流程 - 未选中 |
| `process_active.png` | 合作流程 - 选中 |
| `store.png` | 适用门店 - 未选中 |
| `store_active.png` | 适用门店 - 选中 |
| `contact.png` | 咨询合作 - 未选中 |
| `contact_active.png` | 咨询合作 - 选中 |

## 建议图标风格

- 线条图标，风格统一
- 未选中：浅灰色 `#999999`
- 选中：金色 `#B99448`
- 建议使用简洁线条风格，适配黑金商务主题
